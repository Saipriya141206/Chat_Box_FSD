# Wechat

Wechat is a lightweight, responsive chat-interface demo built with plain HTML, CSS, and JavaScript. It presents a familiar two-pane messaging layout: a searchable contact list and a conversation view with profile details, timestamps, message bubbles, and a composer.

This project is a front-end demo. It does not connect to a messaging service or backend, so simulated replies and locally saved messages are visible only in the current browser.

## Features

- Responsive chat layout with a contact list on desktop and a back-to-chats flow on smaller screens.
- Indian sample contacts with illustrated Big Ears cartoon profile avatars.
- Office and project-planning sample conversation with incoming and outgoing messages.
- Message composer with send button and Enter-to-send behavior.
- Immediate, scripted replies selected from the active contact's reply examples.
- Automatic scroll to the newest message whenever a message is appended.
- Contact search, online-only filtering, and a View all control to clear filters.
- Compose flow for adding a local contact and opening a new conversation.
- Emoji insertion and file selection. File selection adds the file name and size to the chat; it does not upload the file.
- Voice and video call buttons that explain calling is not connected in this demo.
- Local persistence of contacts and conversations with `localStorage`.
- Reduced-motion support and accessible labels on the main controls.

## Run Locally

No package manager, build step, or third-party JavaScript package is required.

The simplest option is to open `index.html` in a modern browser. For a local HTTP server, run this command from the project directory:

```powershell
py -m http.server 8000
```

Then open <http://localhost:8000>.

An internet connection is needed to load the Google Fonts and DiceBear avatar images. The interface and messaging logic are local to the browser.

## How to Use

1. Open the page. The Rahul Sharma conversation is selected by default.
2. Select a contact in the left pane to load that person's conversation and status.
3. Type in the composer and press Enter or select Send. The outgoing message is added, the view scrolls to the bottom, and a contact-specific demo reply appears immediately.
4. Use Search chats to filter by contact name. The filter button toggles online-only contacts. View all clears the search and online filter.
5. Select the plus button to create a local contact and open a new chat.
6. Select the smile button to insert an emoji. Select the paperclip to choose a file; the chat records its name and approximate size only.
7. On a small screen, use the back arrow in the chat header to return to the conversation list.

Press `/` outside a text field to focus the contact search.

## Message and Data Flow

When a message is sent, the app trims the input and ignores an empty message. It creates a timestamped outgoing message, appends it to the active conversation, updates that contact's list preview, scrolls the conversation to the newest message, and saves the updated contacts to browser storage. It then selects one of the active contact's predefined sample replies, appends it immediately as an incoming message, updates the preview again, and saves the conversation.

New contacts and conversation histories are stored under the `vconnect.contacts.v2` key in `localStorage`. Data remains in the same browser storage context across reloads. Clearing the browser's site data removes these local conversations and restores the initial sample data.

## Limitations

- Replies are scripted examples, not generated by a person or AI service.
- There is no user authentication, server, network delivery, or real-time connection between users.
- Voice and video calls are not implemented; their buttons show an informational dialog.
- File attachments are not uploaded or stored as files. Only the selected file's name and size are added as a message.
- Profile illustrations are generated by DiceBear and loaded remotely. They are seeded by contact name; they are not the user-uploaded images.
- Fonts are loaded from Google Fonts, with local fallback fonts if the service is unavailable.
